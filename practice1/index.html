Proyectos

Sistema de Inventario

Aplicación de escritorio para control de entradas y salidas de productos.

Sistema desarrollado en Java para gestionar inventario de una pequeña empresa, con registro de productos, control de stock y reportes básicos. Conexión a base de datos MySQL para persistencia de la información.

Lista de Tareas (To-Do List)

Web app para organizar tareas diarias con JavaScript puro.

Aplicación construida con HTML, CSS y JavaScript que permite agregar, marcar como completadas y eliminar tareas, guardando el progreso en el almacenamiento local del navegador para que persista entre sesiones.

Calculadora de Notas

Herramienta para calcular promedios y estado de aprobación de cursos.

Proyecto que calcula el promedio final de un curso a partir de zonas y examen final, indicando si el estudiante aprueba o no según el criterio ingresado. Incluye validación de datos de entrada.
